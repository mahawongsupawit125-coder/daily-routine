# หน้าเว็บ วันของคุณ

โค้ดหน้าเว็บที่ใช้งานจริง แยกตาม 9 เมนู:

| โฟลเดอร์ใน src/pages | หน้าที่รับผิดชอบ |
| --- | --- |
| 01_dashboard | ภาพรวมและทางลัด |
| 02_body | กรอกข้อมูลร่างกายและผล BMI/REE/TDEE |
| 03_water | บันทึกน้ำ เครื่องดื่ม อากาศและกิจกรรม |
| 04_schedule | ตารางชีวิตรายวัน |
| 05_workout | แผนออกกำลังและวันพัก |
| 06_meals | มื้ออาหาร สารอาหาร และหน้าตรวจรูปอาหาร |
| 07_self_care | ดูแลตัวเองเช้า/บ่ายและรายการที่เพิ่มเอง |
| 08_history | ประวัติที่บันทึกแยกตามวันที่ |
| 09_settings | ตั้งค่า ข้อมูลร่างกาย และนำเข้า/ส่งออก JSON |

`src/shared/app-shell.js` ดูแล state, routing, การบันทึก, navigation และ event handlers ร่วมกัน ส่วน `src/shared/core.js` เป็นการคำนวณและตรวจข้อมูล

ไฟล์ `page.js` เป็นส่วนประกอบของ app เดียวกัน สคริปต์ build นำกลับไปประกอบ ณ ตำแหน่ง `@include` เดิมภายใน closure เดียว จึงใช้ helpers และ state ร่วมกันได้ ห้ามโหลด page.js เหล่านี้ผ่าน script tag โดยตรง

`public/index.html` เป็นโครง HTML ส่วน `assets/styles` และ `assets/icons` เก็บรูปแบบและไอคอนที่เว็บใช้จริง `npm run build` จากรากโปรเจกต์จะสร้าง dist/ โดยรักษาชื่อ URL ของไฟล์ที่เผยแพร่เดิมไว้
