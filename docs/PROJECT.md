## บันทึกข้อมูลรายวัน

1. เลือกวันที่ด้านบนของเว็บ
2. เพิ่มข้อมูลหรือติ๊กสิ่งที่ทำ ระบบจะบันทึกอัตโนมัติเมื่อเปลี่ยนข้อมูล
3. กด **บันทึกวันที่เลือก** เพื่อยืนยันซ้ำ หรือเก็บวันว่างไว้ในประวัติ
4. ดูข้อความ **บันทึกล่าสุด** เพื่อทราบเวลาที่บันทึกสำเร็จ
5. เปิด **ประวัติรายวัน → เปิดดู / แก้ไข** เพื่อกลับไปยังวันนั้น

ข้อมูลอยู่ใน `localStorage` คีย์ `jai-daily.v1` แยกตามเบราว์เซอร์และที่อยู่เว็บ **ยังไม่ซิงก์ข้ามเครื่อง** การล้างข้อมูลเว็บไซต์หรือใช้โหมดส่วนตัวอาจทำให้ข้อมูลหาย ควรสำรองผ่าน **ตั้งค่า → ส่งออก JSON** เป็นระยะ

การนำเข้า JSON จะแทนที่ข้อมูลในเบราว์เซอร์นี้หลังยืนยัน ระบบตรวจรูปแบบก่อนนำเข้า และปรับข้อมูลจากรุ่นเก่าให้เข้ากับฟีเจอร์ปัจจุบัน

## ถ่ายรูปอาหารและวิเคราะห์ AI

ลำดับการใช้งาน: **ถ่าย/เลือกรูป → ระบุปริมาณ วันที่ มื้อและเวลา → ยืนยันส่งวิเคราะห์ → ตรวจแก้ผล → บันทึก**

- รองรับ JPEG, PNG และ WebP ไม่เกิน 20 MB
- ย่อภาพเป็น JPEG ด้านยาวไม่เกิน 1,024 พิกเซลก่อนส่ง
- บนมือถือปุ่มถ่ายรูปขอเปิดตัวเลือกกล้องผ่านเบราว์เซอร์ บนคอมพิวเตอร์เลือกไฟล์รูปได้
- ไม่เดาเวลาที่กินจากภาพ ผู้ใช้ระบุเวลาเอง
- ผลวิเคราะห์เป็นประมาณการ แก้ชื่ออาหาร ปริมาณ และสารอาหารได้ก่อนบันทึก
- การยกเลิกจะไม่เพิ่มมื้ออาหารจากผลที่มาช้า
- รูปไม่ถูกเก็บถาวรในประวัติหรือไฟล์ JSON เก็บเฉพาะผลที่ตรวจแล้วและเวลาที่ระบุ

**สถานะ: เตรียมระบบเชื่อม AI แล้ว แต่ยังไม่เปิดวิเคราะห์ภาพจริง** ผู้ใช้ยังไม่มีบัญชี/กุญแจบริการที่ตั้งค่าไว้ ใช้ปุ่ม **กรอกข้อมูลเอง** ได้ระหว่างนี้

การเปิดใช้ต้องมี OpenAI API และ Cloudflare Worker ตาม [คู่มือเปิดใช้ AI](FOOD-AI-SETUP.md) กุญแจ `OPENAI_API_KEY` อยู่ใน Secret ฝั่งเซิร์ฟเวอร์เท่านั้น

หน้าตั้งค่าเว็บรับสองค่า:

1. URL บริการที่ลงท้าย `/api/analyze-food`
2. รหัสส่วนตัวที่ตั้งเป็น `FOOD_ACCESS_TOKEN` อย่างน้อย 32 ตัวอักษร ซึ่งไม่ใช่ API key ของ OpenAI

รหัสเข้าใช้เก็บเฉพาะความจำของหน้านี้ ต้องใส่ใหม่หลังรีโหลด รูปและรายละเอียดส่งไปยังบริการที่ตั้งไว้และ OpenAI เฉพาะเมื่อผู้ใช้ยืนยันและกดวิเคราะห์

## เปิดในเครื่องและเผยแพร่

ติดตั้ง Node.js 24 ขึ้นไป แล้วดับเบิลคลิก `start.cmd` หรือเปิด Terminal ในโฟลเดอร์โปรเจกต์:

```sh
node server.cjs
```

เปิด `http://localhost:4173` และเปิด server ค้างไว้ระหว่างใช้ ไม่ต้องติดตั้ง dependency เพื่อเปิดตัวแอป

GitHub Pages ใช้ workflow **Publish GitHub Pages** ซึ่งสั่งทำงานด้วยตัวเองหลังอัปโหลดไฟล์ครบ การอัปซอร์สอย่างเดียวไม่เผยแพร่หน้าเว็บอัตโนมัติ ส่วน Worker ต้องเผยแพร่แยกตามคู่มือ AI
