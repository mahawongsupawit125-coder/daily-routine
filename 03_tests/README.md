# ชุดทดสอบ

รัน `npm ci` แล้ว `npm run check` และ `npm test` จากรากโปรเจกต์ คำสั่งจะ build หน้าเว็บก่อนตรวจ source, core calculations, backup/import, DOM interactions, food API, static server และไฟล์ที่เผยแพร่

DOM simulation ไม่ได้ตรวจการจัดวางจริงบนมือถือหรือเบราว์เซอร์ ดูข้อจำกัดใน [QA](../docs/QA.md)
